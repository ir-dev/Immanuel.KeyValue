Free Online Key-Value Store

Store a value, read it back from anywhere. No sign-up, no billing, no SDK — just HTTP. Manage settings, counters and visitor counts in a few lines of code.

Quick start

Three requests. Copy them straight into a terminal.

1 Get an app key

Your app key is the handle to your own private store. Keep it — it cannot be recovered.

curl /api/KeyVal/GetAppKey

# "3cg7aby9"

2 Store a value

Key up to 64 characters, value up to 1024.

curl -X POST \
  /api/KeyVal/UpdateValue/3cg7aby9/yourkey/yourvalue

# true

3 Read it back

Returns an empty string when the key has never been set.

curl /api/KeyVal/GetValue/3cg7aby9/yourkey

# "yourvalue"

Use it from JavaScript

No dependencies. Drop this in and call the three functions.

<script>
const KV_BASE = "";

async function getValue(appKey, key) {
  const res = await fetch(`${KV_BASE}/api/KeyVal/GetValue/${appKey}/${key}`);
  return res.ok ? res.json() : null;
}

async function updateValue(appKey, key, value) {
  const res = await fetch(
    `${KV_BASE}/api/KeyVal/UpdateValue/${appKey}/${key}/${encodeURIComponent(value)}`,
    { method: "POST" });
  return res.ok;
}

async function actOnValue(appKey, key, action) {   // "increment" | "decrement"
  const res = await fetch(
    `${KV_BASE}/api/KeyVal/ActOnValue/${appKey}/${key}/${action}`,
    { method: "POST" });
  return res.ok ? res.json() : null;
}
</script>

A visit counter is one line on page load: actOnValue("3cg7aby9", "visits", "increment"). The key is created at zero the first time, so there is nothing to set up.

API reference

v1 is the original API, unchanged and supported indefinitely. v2 adds listing, deleting, bigger values and richer responses.

v1 — unchanged since 2017

MethodPathDoes
GET/api/KeyVal/GetAppKeyIssue a new app key
GET/api/KeyVal/GetValue/{appkey}/{key}Read a value, or ""
POST/api/KeyVal/UpdateValue/{appkey}/{key}/{value}Create or overwrite
POST/api/KeyVal/ActOnValue/{appkey}/{key}/{action}increment or decrement
GET/api/KeyVal/GetCountKeys stored service-wide
GET/api/KeyVal/GetIpYour IP as the server sees it

v2 — recommended for new code

MethodPathDoes
POST/api/v2/appkeysIssue a new app key
GET/api/v2/appkeys/{appkey}Key count and timestamps
GET/api/v2/appkeys/{appkey}/keysList everything you stored
GET/api/v2/appkeys/{appkey}/keys/{key}Read one key with timestamps
PUT/api/v2/appkeys/{appkey}/keys/{key}Set from a JSON body: {"value":"..."}
DEL/api/v2/appkeys/{appkey}/keys/{key}Remove a key
POST/api/v2/appkeys/{appkey}/keys/{key}/incrementStep by {"by":n}, default 1
GET/api/v2/statsService-wide totals

Sending the value in a JSON body means it can contain slashes, newlines and anything else a URL path segment cannot carry. Machine-readable schema: /openapi/v1.json.
